## Project Overview

**FunBros** is a fast-paced 2D platformer developed using the **Godot Engine** and **GDScript**. The game focuses on smooth movement, precise timing, and engaging enemy interactions across **three fully playable levels**. Players run, jump, and roll through colorful environments filled with traps, enemies, and checkpoints.

Each level introduces increased difficulty, new enemy placements, and more complex platforming challenges — delivering a complete and enjoyable platformer experience from start to finish.

---

## Key Features

- Classic 2D platformer gameplay
- Smooth player movement and responsive controls
- Three fully designed levels with progressive difficulty
- Multiple enemy interactions with jump and roll mechanics
- Life-based system with intelligent respawn behavior
- Checkpoint-based progression system
- Environmental hazards, traps, and pitfalls
- Colorful and engaging level design
- Complete and playable final game

---

## Gameplay Mechanics

| Action | Behavior |
|--------|----------|
| Run / Jump / Roll | Core player movement set |
| Jump on enemy | Defeats the enemy |
| Roll into enemy | Defeats the enemy |
| Fall into pit / enemy contact | Reduces player lives |
| Reach checkpoint | Saves progress within the level |
| Lose a life | Respawn at the last checkpoint |
| Lose all lives | Game resets to the beginning |

---

## Game Design Philosophy

FunBros is built around simple mechanics paired with meaningful challenges. The gameplay emphasizes timing, movement precision, and player decision-making over complex controls.

Design priorities include fair enemy encounters, clear visual feedback, gradual difficulty progression across levels, and fast respawn cycles that keep the experience challenging yet fun.

---

## Technical Highlights

- Custom player movement logic for smooth, responsive controls
- Physics-based enemy interaction handling
- State-driven player actions (idle, run, jump, roll)
- Modular and scalable script architecture
- Checkpoint system implementation
- Structured level design supporting multiple stages
